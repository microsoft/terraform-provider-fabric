### 💫 Changed

* [#1146](https://github.com/microsoft/terraform-provider-fabric/issues/1146) Removed the ARM_ENVIRONMENT fallback for Fabric environment selection. Use the provider environment argument or FABRIC_ENVIRONMENT instead; other ARM credential fallbacks remain unchanged.

### ⚰️ Deprecated

* [#1146](https://github.com/microsoft/terraform-provider-fabric/issues/1146) Deprecated `members.microsoft_entra_members.object_type` in OneLake data access security. The resource attribute is now optional and ignored by the API, with configured values retained in state for compatibility. Data sources continue to return null. Remove the attribute from configuration and references before its removal in a future major provider version.

### 🪲 Fixed

* [#1146](https://github.com/microsoft/terraform-provider-fabric/issues/1146) Fixed OneLake data access security `members.fabric_item_members` to default to an empty set when omitted or null, matching the API and avoiding inconsistent results after apply. Removing configured members now clears the collection without recurring diffs.

### 📚 Documentation

* [#1140](https://github.com/microsoft/terraform-provider-fabric/issues/1140) Fixed `processing_mode` value casing (`"parameters"` → `"Parameters"`) in resource examples
