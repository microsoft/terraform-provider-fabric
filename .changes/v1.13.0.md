## v1.13.0 - August 16, 2026

### ✨ Added

* [#1065](https://github.com/microsoft/terraform-provider-fabric/issues/1065) Added virtual network gateway member autoscaling support via `min_member_gateway_count` and `max_member_gateway_count`.
* [#1076](https://github.com/microsoft/terraform-provider-fabric/issues/1076) Added support for Spark runtime version `2.0` in the `fabric_spark_workspace_settings` resource and data-source.

### 🪲 Fixed

* [#1066](https://github.com/microsoft/terraform-provider-fabric/issues/1066) Fixed `fabric_gateway` and `fabric_gateways` data sources failing with an `Unsupported Gateway type` error when a `StreamingVirtualNetwork` gateway was present
